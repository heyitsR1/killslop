Guide

Install KillSlop in three steps.

Under a minuteChrome, Edge, Brave and other Chromium browsers

The easiest way to get KillSlop is the Chrome Web Store, which keeps it updated for you. This guide is for installing it straight from GitHub instead. It takes three clicks. Your settings stay in your browser either way.

Step 1

Download the zip and unzip it

Open the latest KillSlop release and under Assets, click the zip whose name starts with killslop-. Double-click the downloaded zip to unzip it. You get a folder; keep it somewhere you will not delete, because Chrome runs KillSlop from that folder.

Step 2

Turn on Developer mode

Type chrome://extensions into the address bar and press Enter. In Edge it is edge://extensions, in Brave brave://extensions. Switch on Developer mode at the top right. A row of new buttons appears.

Step 3

Choose Load unpacked and pick the folder

Click Load unpacked, then select the folder you unzipped in step 1: the folder itself, not a file inside it. KillSlop appears on the page with its switch on. That's it.

The folder picker in the animation is drawn for clarity; yours looks like your computer's own.

Optional

Pin it, then open X

Click the puzzle piece next to the address bar and the pin beside KillSlop, so its switch and the dashboard are one click away. Then open X: replies from listed bots fold into a thin card that says why, with Show to read one anyway.

Questions

Is Developer mode safe to leave on?

Yes. It only lets you load extensions from a folder. Chrome may show a reminder about developer-mode extensions when it starts; you can close it.

How do I update it?

The bot list updates itself every few hours, with no reinstall. For a new version of the extension itself, download the new zip, replace the folder, and press the reload arrow on KillSlop's card in chrome://extensions. Or switch to the Chrome Web Store copy, which updates on its own.

Where does the bot list come from?

It is built on levelsio's Blocked for AI reply list, with Clankwall and our own reviewed list. KillSlop is not affiliated with any of them, or with X.

Something went wrong

If Chrome says the manifest is missing, you picked a file or the wrong folder: pick the folder that contains manifest.json. Anything else, tell us here.
